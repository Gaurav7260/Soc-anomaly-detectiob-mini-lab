# SOC Detection System

A practical cybersecurity lab project focused on network traffic analysis, SIEM monitoring, log analysis, detection engineering, and SOC workflows.

---

# Phase 1 — Wireshark Network Traffic Analysis

## Topics Covered
- TCP packet analysis
- SYN packet inspection
- TCP 3-way handshake
- Packet capture investigation
- Source and destination IP analysis

## Tools Used
- Wireshark
- Kali Linux
- Windows VM
