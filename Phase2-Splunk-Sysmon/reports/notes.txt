PHASE 1 — WINDOWS SECURITY LOG DETECTION LAB

Objective:
Build a beginner SOC lab using Splunk, Windows VM, and Kali Linux.

Lab Setup:
- Host Machine: Mac
- SIEM Tool: Splunk Enterprise
- Attacker Machine: Kali Linux VM
- Victim Machine: Windows 11 VM

IP Addresses:
- Kali Linux: 192.168.20.15
- Windows VM: 192.168.20.16

Activities Performed:
1. Verified connectivity between Kali and Windows using ping.
2. Installed and configured Splunk Enterprise.
3. Enabled Windows Event Log ingestion.
4. Successfully ingested Security Event Logs into Splunk.
5. Generated failed login attempts on Windows.
6. Detected EventCode 4625 (failed login events).
7. Used SPL queries to investigate failed authentication activity.

Important Event Codes:
- 4624 = Successful Login
- 4625 = Failed Login
- 4672 = Special Privileges Assigned

SPL Queries Used:
index=main sourcetype="WinEventLog:Security"

index=main EventCode=4625

index=main EventCode=4625
| stats count by Account_Name

Outcome:
Successfully built a functional SOC monitoring lab capable of ingesting and detecting Windows security events using Splunk.
